# TrendVision AI

TrendVision AI is a predictive analytics web app for forecasting market trends, comparing topics, tracking watchlists, and generating AI-powered reports. It provides interactive charts, historical analysis, confidence scores, keyword insights, model selection, dataset validation, prediction archives, user profiles, and downloadable PDF reports.

## Technology

React, TypeScript, Vite, Express, Recharts, jsPDF, and html2canvas.

## Run locally

1. Install dependencies: `npm install`
2. Add `GEMINI_API_KEY` to `.env.local`
3. Start the development server: `npm run dev`
